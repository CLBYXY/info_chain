## 2. 测试准备

1. 打开产品首页，确认能够新建对话；记录网址、部署版本、时间及左下角模型状态。
2. 在 Render 配好金融数据和模型密钥，不在截图、录像、测试报告中展示密钥。正常流程先确认公司代码能被识别。
3. 建议先用独立测试浏览器或无痕窗口，避免和真实演示会话混淆。匿名用户 ID 保存在当前浏览器中；无痕窗口会获得另一身份。
4. 页面回答可能复用同一问题、身份、自选股组合 10 分钟内的结果。测试故障或不同模式时，换一个问题、等待缓存失效，或在独立测试服务重启；仅新建对话不保证绕开服务端缓存。外部数据和 LLM 另有磁盘缓存，模型错误测试也应注意缓存命中。
5. 外部接口故障注入仅在本地副本或单独的 Render 测试服务进行。修改环境变量后重启服务，测试完恢复原值。不要在唯一的提交演示服务上反复换密钥。

### 4.1 在当前网页直接操作：前端网络故障

使用 Chrome 或 Edge 的开发者工具（F12）：

1. 先正常生成一条回答，保留截图。保持一个已有对话打开，避免“新建会话接口失败”干扰提问接口测试。
2. 在 Network（网络）面板找到发起提问的 `.../api/conversations/.../ask` 请求。可以先正常发送一个问题以便定位。
3. 右键该请求，选择阻止请求网址（Block request URL）。确认“请求阻止”已启用，再发送新问题。
4. 截图记录被阻止的请求和页面“发送失败”提示。取消阻止后重新输入并发送，确认恢复。
5. 另做轮询中断：正常发送问题，出现进度后把 Network 的网络条件设为 Offline；过数秒再设回 No throttling/Online，观察能否取得回答。
6. 测试完成关闭所有阻止规则、恢复在线。离线时不要刷新页面，否则可能连网页本身也加载不了。

**解释：**上述操作只切断浏览器到本站的连接。网站服务器访问 DeepSeek、扶摇、巨潮的连接不经过你的浏览器，不能通过浏览器屏蔽这些域名来验证服务器的降级逻辑。

### 4.2 网页发起的后端故障测试：独立测试服务

不需要改网页代码，但需要修改测试服务配置后重启：

1. 模型关闭基线：设置 `EVENTLENS_LLM=off`，重启，提出一条全新的明确事件问题。回答应可按规则生成，处理记录显示未启用 LLM。此例验证“禁用模型”，不验证“模型接口报错”。
2. 模型故障：恢复 `EVENTLENS_LLM=auto`，供应商设为 `deepseek`，使用非空测试占位密钥，并把 `DEEPSEEK_BASE_URL` 临时设为 `http://127.0.0.1:9`（不可用的本机端口）。重启，在网页提交未缓存问题；查看是否显示模型连接失败并按规则降级。保留金融接口有效配置，以免前置标的识别失败掩盖模型降级。
3. 金融接口故障：在另一轮把 `FUYAO_BASE_URL` 临时设为 `http://127.0.0.1:9`，重启后提交新的公司事件问题。记录是否停在澄清标的阶段、是否避免编造。命中历史缓存不算故障已触发。
4. 巨潮公告/PDF 故障没有现成网页开关；现有自动测试通过替身注入 `SourceError`。若需精确验证某一个真实响应码、坏 JSON、PDF 解码或超时，应在独立测试环境增加接口替身/代理后再执行，不能声称按钮已覆盖。
5. 恢复原有环境变量并重新部署，重跑一条正常问题，确认恢复。录屏和报告中不显示原始密钥或完整服务端错误凭证。

### 合规检查的实际限制

- 当前“禁止词”主要检查产品生成的结论，不等于全文语义审查。原文证据可能包含买卖措辞，应保留来源归属，人工核对产品有没有采纳其建议。
- 数字检查验证数字是否出现在可用证据或计算结果中，不足以证明单位、对象、因果和整句含义都正确；必须人工回查。
- 公司声明中的事实、观点、推测、传闻允许类型由规则约束；软判定失败退回允许集合。`test_allowed_types`、`test_soft_judge_fallback_stays_inside_allowed` 已覆盖相应构造样例，不代表所有真实文本分类正确。
- 新闻、研报尚未接入；“最早来源”只能指当前已接入材料里的最早记录，尤其不能把公告转述日期冒充传闻在全网的首发日期。
- 未覆盖完整权限、限流、并发压力和隐私安全审计；管理接口无登录、任务仅存内存、匿名身份不是账号认证。当前演示系统不能据此宣称达到生产合规要求。

## 6. 可复现的自动测试

Windows 项目根目录执行（需要已安装 pytest）：

```powershell
$env:EVENTLENS_LLM = 'off'
.venv/Scripts/python.exe -m pytest -q tests
```

Linux/Render 风格环境：

```bash
EVENTLENS_LLM=off python -m pytest -q tests
```

需要安装测试工具时执行 `python -m pip install pytest==8.3.4`；运行依赖见 `requirements.txt`。本套测试主要覆盖规则和模块行为，不是启动真实网页的端到端套件。金融接口失败测试对取数函数做替身注入，四种更新通过构造快照检查，不依赖真实新闻更新。
